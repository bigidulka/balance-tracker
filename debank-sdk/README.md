# Wallet Tracker Bot

Простой Telegram-бот на `aiogram` с быстрым UI через inline-кнопки и отдельным backend API поверх локального `debank-sdk`.

## Сервисы

- `backend`: Node.js API, работает с `debank-sdk`, кэширует ответы и хранит watchlist в SQLite.
- `frontend`: `aiogram`-бот, который держит single-message UI и редактирует один основной экран вместо спама сообщениями.

## Что умеет

- добавлять кошельки в трек;
- смотреть список отслеживаемых адресов;
- быстро получать summary по адресу через inline-сценарий или просто отправив адрес в чат;
- показывать экран загрузки `⏳`, пока backend получает данные.

## Запуск

1. Создайте `.env` на основе `.env.example`.
2. Запустите:

```bash
docker compose up --build
```

## Архитектура UI

- Навигация только через inline buttons.
- Основной сценарий работает в одном bot message.
- `Back` использует стек экранов в FSM, а не статический target.
- Ввод адреса запускается только после inline-действия `Добавить кошелек` или `Быстрый поиск`.

## Структура

- `backend/`: HTTP API и SQLite.
- `frontend/`: aiogram UI.
- корень репозитория: сам SDK `debank-sdk`, который backend подключает как локальный пакет.
